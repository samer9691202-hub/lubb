# مِداد — الإصدار 1.0.0

مشروع مستقل جديد، مبني من الصفر بهوية زرقاء داكنة وهوية بصرية هندسية بسيطة. لا يعتمد على ملفات LUBB أو قاعدة بياناته.

## التقنية
- HTML / CSS / JavaScript Modules دون إطار عمل ثقيل.
- IndexedDB للتخزين المحلي المنفصل.
- PWA + Service Worker للتشغيل دون اتصال بعد أول تحميل.
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.

## الوظائف الموجودة
- لوحة رئيسية وإحصاءات مختصرة.
- مهام: إضافة، تعديل، حذف، إكمال، أولوية، موعد، بحث وتصفية.
- ملاحظات: إضافة، تعديل، حذف، بحث.
- تخطيط شهري ومواعيد: إضافة وحذف وعرض.
- سجل موحد للأنشطة.
- إعدادات المظهر الداكن.
- تصدير واستعادة نسخة JSON محلية.
- قفل PIN اختياري على مستوى الجلسة.

## التشغيل
يجب تشغيل المجلد من خادم محلي أو استضافة HTTPS حتى تعمل JavaScript Modules وService Worker. افتح `index.html` بعد رفع المجلد إلى استضافة مناسبة.

## ملاحظات الإصدار الأولي
- لا توجد مزامنة سحابية؛ البيانات محفوظة على الجهاز داخل IndexedDB.
- استعادة النسخة تدمج السجلات ولا تستبدل قاعدة البيانات بالكامل.
- PIN في هذا الإصدار قفل محلي اختياري وليس تشفيراً للبيانات.
- التذكيرات والتنبيهات الدورية، تكرار المهام، التشفير بكلمة مرور، وعبارة استعادة مشفرة ليست ضمن هذا الإصدار الأولي بعد.
- الخط من Google Fonts مع بدائل محلية؛ الواجهة الأساسية تعمل دون الخط الخارجي.
