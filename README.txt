LUBB — AppMint Front-End Design 1.0.0

حزمة واجهة مستقلة جاهزة كنقطة بداية للتحويل إلى تطبيق عبر AppMint.
اجعل index.html صفحة البداية وأضف الملفات الثلاثة معاً إلى مشروع Web App.

الملفات:
- index.html: واجهة عربية RTL.
- styles.css: تصميم متجاوب للكمبيوتر والهاتف، دون مكتبات خارجية.
- app.js: التفاعل والبيانات المحلية.

الأقسام: اليوم، القادم، الوارد، كل المهام، مشاريع العمل، شخصي، أفكار لاحقاً، التقويم، الملاحظات، التذكيرات، الأرشيف، الإعدادات.

المتوفر: إضافة وتعديل المهام، إكمال المهام، تنظيمها حسب القائمة والتاريخ والأولوية، إضافة وتعديل الملاحظات، تذكيرات داخل الواجهة، تقويم شهري، تصدير واستيراد JSON، وحفظ محلي باستخدام localStorage.

مهم قبل النشر:
- التذكيرات الحالية لا ترسل إشعارات Android حقيقية؛ يلزم ربطها بإشعارات النظام في AppMint.
- الحفظ الحالي عبر localStorage على الجهاز/المتصفح، وليس مزامنة سحابية.
- هذا تصميم مستقل وليس دمجاً مع مشروع سابق أو استيراداً لبياناته.
- اختبر أذونات التخزين والتنزيل والاستيراد وسلوك WebView على Android بعد التحويل.
- لا توجد مكتبات CDN مطلوبة، ويمكن تشغيل الواجهة دون إنترنت بعد تضمين الملفات.
