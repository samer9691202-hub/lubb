LUBB — UI Design Prototype
==========================

هذه حزمة نموذج تصميم واجهة أمامية تجريبية لتطبيق LUBB، مبنية من الصفر وفق وثيقة المواصفات:
- واجهة عربية RTL ومتجاوبة للهاتف واللوحي والحاسوب.
- لوحة رئيسية، قائمة جانبية، بطاقات إحصائية، مهام، تذكيرات، تقويم مصغر وملاحظات.
- صفحات تصورية للتقويم والمهام والملاحظات والقاعدة الرئيسية والإعدادات.
- تفاعلات عرض الأقسام، طي القائمة، قائمة الهاتف، ساعة حية، وإضافة تجريبية.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.

مهم:
هذا نموذج تصميم Front-end وليس ترقية للمشروع الأصلي ولا يحتوي على قاعدة البيانات أو وظائف التخزين والنسخ الاحتياطي وPIN والإشعارات وService Worker. لا ترفع هذه الحزمة فوق مشروعك الحالي باعتبارها بديلاً عنه. يلزم دمج التصميم واختباره داخل ملفات LUBB الأصلية للحفاظ على البيانات والوظائف.
الألوان معرفة كمتغيرات CSS أعلى styles.css ويمكن مواءمتها بدقة مع ألوان الهوية الأصلية عند توفرها.
